# 4SC0 legacy wave — 2026-09-28

Operator direction (via demo session): *"the 4SC0 legacy wave"* — give the demo's
Science Double Award (2017) **physics** course its legacy pairing, mirroring what the
4SD0 wave (docs/4SD0-2026-09-27.md) did for chemistry.

## Structural finding (the reason this wave touches physics/4ph0, not a new 4sc0 folder)

The demo's double-award physics reconstructions carry legacy `sourcePaper` tags
(sessions 2012–2016, refs `1P`/`2P`/`1PR`/`2PR`). Investigation established:

1. **The legacy 4SC0 Science Double Award was assessed via the single sciences' Paper 1s.**
   Edexcel IGCSE Science (Double Award) 4SC0 spec, Issue 3 (Nov 2009), "Specification at
   a glance": *"This Edexcel IGCSE in Science (Double Award) comprises three externally
   assessed papers: Biology Paper 1, Chemistry Paper 1, Physics Paper 1"* — paper codes
   `4SC0/1B`, `4SC0/1C`, `4SC0/1P`, each 2 hours, first assessment June 2011. The spec's
   assessment table shows Paper 2 (1 hour) belongs to the single sciences only
   (core + extension → IGCSE in Biology/Chemistry/Physics); the Double Award = core papers.
   Spec PDF: `qualifications.pearson.com/content/dam/pdf/International GCSE/Science (Double Award)/2009/Specification and sample assessments/IGCSE-Science-Dble-Awd-4SC0-Issue-3-1-1.pdf`
2. **Pearson's own DAM catalogs the shared papers under both subjects.** The
   `Qualification-Subject/Science-(Double-Award)` DAM listing contains, for every legacy
   session (Jan 2012–Jan 2019, Jun 2012–Jun 2018), the `4BI0/4CH0/4PH0` question papers
   and mark schemes. The only `4SC0_`-named assets on the DAM are three June-2011 mark
   schemes (`4SC0_1B/1C/1P_rms_20110824a.pdf`) — the first session, before the covers
   consolidated on the single-science codes.
3. **The shared covers print both codes.** Every readable R-variant Paper 1 cover in this
   wave prints `4PH0/1PR` AND `4SC0/1PR` plus the "Science (Double Award)" wording
   (2016-06, 2017-06, 2018-06 verified; the non-R corpus Paper 1s similarly print
   `4SC0/1P` — e.g. 2013-01, 2016-01). This is the same content-sharing pattern the
   corpus already records for 4SD0 ≡ 4BI1/4CH1/4PH1, one era earlier.

Consequence: the honest corpus home for these papers is the EXISTING
`international-gcse/physics/4ph0` spec (Paper 1s of it serve both qualifications);
creating a `4sc0` spec folder would be fabrication — no 4SC0-named question papers exist.

(60 min) — R variants print the same timings as the base papers.

## Gaps honestly left open

- **No January R-variants exist** (any year) — Pearson's DAM lists 1P/2P only for Jan
  sessions; confirmed across the full DAM series census.
- **No June 2012 R-variants** — DAM lists 1P/2P only for 2012-06.
- **June 2015 1PR QP is absent from Pearson's DAM** (mark scheme present). The corpus
  dir is ms-only; no official blueprint can be extracted from a QP, so any demo
  reconstruction matched to it stays honestly "unverified".
- 2013-06 QP covers have a broken ToUnicode CMap (text layer extracts as mojibake) —
  identity for those two dirs is rank 3 (official listing label + exam-date-coded
  filename), the wave-8 precedent.
