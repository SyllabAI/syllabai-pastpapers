## Wave machine (agent workspace `scripts/wave_er/`)

dump (family-partitioned pagination, 10k/page cap) → join → fetch (8-thread, resumable

1..i); broken chain never left the machine (no ref ever pointed at it).

## Identity law (README §14, uniform for every file)

HTTP 200 full-body → `%PDF` magic → `pymupdf` open + page count → **printed-PDF-text
identity on pages 1–5**: spec code + paper reference + session (month name or season
synonym) — plus three narrow documented alias rules (33 files; alias recorded in the
manifest note):
1. printed-code transposition `4MP0` → 4PM0 (url-of-record cross-checked);
2. zero-stripped paper ref printed in context (`Paper 1` for `01`, `4MB0/1R` for `01R`);
3. legacy IAL unit-report form `IAL <Subject> Unit N` (establishes code + the unit's
   single paper `01`), e.g. `IAL Physics Unit 6` → WPH06-01.
sha256 + size recorded in the manifest row; every row carries the full Pearson source_url.
