## 3. Findings

### 🔴 F1. Wrong PDF in `ial/mathematics/wma01/2014-01/WME02-01/qp.pdf` — REPAIRED §6
The file was byte-identical (sha256 `fcb29ee1…`) to `gce-a-level/mathematics/mathematics-modular/2014-01/6663-01/qp.pdf` and printed **"Core Mathematics C1", ref 6663A/01** — not the WME02/01 Mechanics-2 paper. Its sibling `ms.pdf` was the correct Mechanics-2 MS, so the dir was internally mismatched. Root cause: identity "inherited from same-series complementary partner" (partner inference, not PDF-text verification) plus a PMT filename collision (`January 2014 (IAL) QP.pdf` vs `January 2014 QP_2_2.pdf`). The true M2 QP was not lost — the ingestion pipeline had quarantined it as `duplicate-artifact`.

### 🔴 F2. Orphan file with no manifest — `ial/chemistry/wch11/2019-01/WCH11-01/ms.pdf` — REPAIRED §6
The only corpus artifact that was (a) not manifest-backed, (b) an MS-only partial dir, and (c) contradicted by its own ledger (MS row `na:duplicate-row`, QP row stuck at `fetched`). Committed in `73abb9a` despite BACKFILL-REPORT §5's "manifest-complete / no partial states" claim — the source of the 169-vs-170 chemistry dir discrepancy. Print verification showed both artifacts to be genuine WCH11/01 January 2019 documents.

### 🟠 F3. International-variant label under UK GCE — `gce-a-level/mathematics/mathematics-modular/2014-01/6663-01/` — OPEN (operator decision)
Both files print **"Pearson Edexcel International Advanced Level — Core Mathematics 1 (6663A/01)"** — the international 6663**A** variant — while the dir claims GCE `6663/01` and the manifest identity came from `date_rule` (confidence rank 5, `printed_references_seen: []`). QP/MS are a consistent pair. Options: correct the ref to `6663A-01`, annotate the A-variant in the manifest, or re-home if 6663A is deemed IAL-family. The same date-rule spot-check is advised for all 34 confidence-5 manifests.
